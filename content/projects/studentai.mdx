# ML Student Dropout Prediction: Data-Driven Retention
A machine learning and data analysis project designed to predict student dropout rates. By thoroughly processing raw data and applying various classification algorithms, this project seeks to identify at-risk students based on historical data.

This project was developed to explore the end-to-end data science lifecycle, focusing on data cleaning, exploratory data analysis, and evaluating multiple machine learning models to solve a real-world educational problem.

## The Challenge
The main objective was to take raw student data, perform necessary cleaning and preprocessing, and build robust predictive models. The challenge involved handling raw CSV datasets, preparing the features for training, and comparing different algorithms to find the most effective approach for predicting dropouts.

## Technologies and Tools
* **Language:** Python
* **Environment:** Jupyter Notebooks (`.ipynb`)
* **Machine Learning Models:** Logistic Regression, Decision Tree, Gradient Boosting, and K-Nearest Neighbors (KNN)
* **Data Management:** Raw and processed CSV data handling

## Key Features
* **Data Preprocessing:** Comprehensive cleaning pipelines to transform raw data (`data.csv`) into model-ready datasets (`data_cleaned.csv`).
* **Exploratory Data Analysis:** Dedicated analysis notebooks (e.g., `Analysis_Persona2.ipynb`) to understand underlying patterns and student profiles.
* **Multiple ML Algorithms:** Implementation of diverse models to tackle the classification problem, including Gradient Boosting, Logistic Regression, and Decision Trees.
* **Train/Test Validation:** Structured data splitting (`data_train.csv`, `data_test.csv`) to accurately evaluate model performance.

## Development Process
As an end-to-end machine learning project, the development cycle included:
* **Data Preparation:** Raw datasets were cleaned and preprocessed using dedicated Jupyter notebooks (`Limpieza_de_Dataset.ipynb`, `cleaning_and_preprocessing.ipynb`) to handle inconsistencies and format the data.
* **Data Analysis:** Performed exploratory dataset analysis to understand features and relationships.
* **Model Development:** Developed individual Python scripts for distinct machine learning models: `0_logistic_regression.py`, `1_decision_tree.py`, `2_Gradient_Boosting.py`, and `2_KNN_model.py`.
* **Evaluation & Dependency Management:** Split the processed data into training and testing sets, and maintained a `requirements.txt` file for easy environment replication.
