## The Challenge & Objective

Grocery shopping and pantry management often suffer from latency, forgotten items, and friction during physical interactions. The objective of **NFC Shopping List** was to bridge physical hardware and modern web applications by combining Near Field Communication (NFC) with instantaneous cloud synchronization.

Key technical requirements included:
* **Zero UI Latency:** Applying **Optimistic UI** patterns so user actions feel instantaneous even on spotty cellular connections.
* **Multi-Device Live Sync:** Ensuring family members or roommates share an updated list state in real time as items are checked off.
* **Physical-to-Digital Bridge:** Allowing users to tap physical NFC tags (e.g. mounted on a pantry shelf or fridge) to launch the app and quickly append supplies.

## Architecture & Data Flow

```
  [Physical NFC Tag Tap]
            │
            ▼
  [Mobile Browser Client (React + TypeScript)]
            │
    ┌───────┴───────┐
    ▼               ▼
[Optimistic UI]   [Supabase Client (PostgreSQL)]
(Instant render)    │
                    ▼
            [Realtime WebSocket Broadcast]
                    │
                    ▼
          [Synced Client Devices]
```

1. **Hardware Trigger:** Standard NFC tags configured with URI records invoke the web application on smartphones via native Web NFC or OS-level URL dispatching.
2. **Optimistic Client State:** Local state immediately updates item status on the screen before the network round-trip finishes, rolling back gracefully only if an error occurs.
3. **Realtime Broadcast:** Supabase handles PostgreSQL row-level changes and broadcasts live change events over WebSockets to all subscribed devices.

---

## Key Technical Highlights

* **Real-Time Synchronization:** Leverages Supabase Realtime subscriptions to reflect additions, edits, and status changes concurrently across all connected screens.
* **Optimistic UI Architecture:** Eliminates perceived network latency when ticking off items in supermarket aisles with weak connectivity.
* **Automated Smart Grouping:** Intelligently categorizes grocery items to optimize the physical shopping path through aisles.
* **Smart History & Cleanup:** Built-in batch pruning tools that clear completed items while maintaining historical usage metrics for repeat purchases.
* **Automated CI/CD Pipeline:** Uses GitHub Actions for continuous automated builds, type checking, and zero-downtime deployment to GitHub Pages.
